# Effective inseparability of closed lambda normal-form languages

The closed terms that reach a Church numeral and the closed terms that reach a nonnumerical beta-normal form are disjoint recursively enumerable languages. Given codes for disjoint recognizer supersets on closed terms, a primitive-recursive productive map returns a closed term outside both supersets. In particular, no total computable Boolean procedure separates the languages.

The proof transports the existing closed zero/one productive-pair theorem through a primitive-recursive term transformation and a primitive-recursive recognizer-code transformation. A fixed evaluator code is chosen by existence; no algorithm for extracting such a code from an arbitrary computability proof is asserted. The inherited normal-order observer distinguishes a defined nonnumerical normal form from the absence of a reachable normal form. The construction does not treat the mere absence of a numeral as divergence.

The predecessor formalization adapts classical recursion-theorem and inseparability arguments documented in Andrew Marks, *Computability theory*. Challenge fixes the term model, syntax coding, normal observer, both languages and source transformation; its isolated theorem holes are not imported by Solution.
