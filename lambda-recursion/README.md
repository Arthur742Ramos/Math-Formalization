# Recursion and effective inseparability for closed lambda programs

For every fixed computable transformation of parameterized lambda syntax, there is a primitive-recursive family of closed terms with matching partial numerical observations under full beta reduction. The transformation may return open terms. A self-code application returns the project's canonical syntax encoding as a Church numeral on every numeral input; it does not claim literal source reproduction.

The closed terms returning zero or one on input zero form disjoint recursively enumerable languages. A primitive-recursive productive map takes codes for recognizer supersets that are disjoint on closed terms and returns a closed term accepted by neither. The proof selects fixed recursive codes by existence; it does not claim an executable extractor from arbitrary computability proofs. A missing numerical result is not automatically divergence.

The standalone Challenge fixes syntax, coding, numerical semantics, the two languages and recognizer acceptance. Seven theorem holes are comparator obligations and are not imported by the Solution. The package adapts classical computability results to the explicit lambda model and does not claim new mathematics.
