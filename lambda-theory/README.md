# Computability theory for closed lambda programs

Draft package. The independent Challenge gives concrete de Bruijn syntax, full-beta reachability, the canonical term encoding and ten theorem obligations. The Solution imports the proof modules from the pinned predecessor. Challenge holes are not Solution dependencies.

The results concern Church-numeral observations, including nonnumerical outcomes; absence of a result is not a divergence claim. The normal-form theorem has an explicit computable predicate and proves a computable many-one reduction. It selects a fixed recursive code in the proof and does not claim uniform code extraction from proofs.

The lockfile was generated against the public proof checkpoint and its pinned dependencies. An incremental Lake build passed with previously built dependency artifacts. Independent review of this package, protected comparison, mutation controls and service checks are pending. This directory is not submission-ready.
