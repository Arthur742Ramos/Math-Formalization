# Numerical refinement and equivalence of closed lambda programs

This successor package proves computable many-one completeness for universal-existential normal forms for numerical graph inclusion and extensional equivalence of closed untyped lambda programs. The fixed-zero hardness reductions are primitive recursive. The combined reductions from arbitrary computable predicates are stated as computable, with no stronger claim. Numerical observations use full-beta reachability after Church-numeral input; absence of a numerical result is not identified with divergence.

The Challenge contains five theorem obligations and the fixed syntax, encoding, and witness definitions. The Solution does not import the Challenge. The package builds on registered predecessor PALOMAR-2026-11-01-000031 version 1 at commit 236c361f809b2004cde6ecbed679c864bd16ee90, and on lambda/Turing predecessor PALOMAR-2026-11-01-000026 version 1. It vendors the prior proof modules with their notices.

The prior standalone proof was independently reviewed. Integrated package validation and protected comparison are pending; this is not a submission-ready release.
