# Cofinite numerical domains of closed lambda programs

The cofinite numerical-domain predicate for closed untyped lambda programs is complete under computable many-one reductions for computable existential-universal-existential Boolean normal forms. The package also proves many-one equivalence with cofinite domains of partial-recursive codes. Its hardness construction uses a finite-injury marker argument and a fixed evaluator code selected for each computable predicate.

Numerical observations are Church numerals reachable by full beta reduction after application to a numeral. Absence of a numerical observation is not automatically divergence. No executable extractor from arbitrary computability proofs or arbitrary Turing-machine syntax translation is asserted.

The standalone Challenge fixes the term syntax, encoding, numerical semantics, cofinite predicate and bounded witness. Its four theorem holes are comparator obligations and are not imported by the Solution. This adapts a classical computability classification to the explicit lambda model; it is not a claim of new mathematics.
