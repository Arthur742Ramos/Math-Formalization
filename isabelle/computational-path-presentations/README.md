# Computational Path Presentations

A standalone Isabelle2026 development of typed computational witnesses,
executable free structural normalization, and conservative changes of
presentation. The actual AFP-style entry is in `Computational_Path_Presentations/`.

Read the [theorem and scope guide](Computational_Path_Presentations/README.md),
[source correspondence](SOURCE_CORRESPONDENCE.md),
[external dependency pins](AFP_DEPENDENCY.md), and
[validation guide](VALIDATION.md).

This repository is not an AFP submission and does not claim AFP acceptance,
human mathematical review, a topology formalization, or a HoTT interpretation.
It preserves explicit boundaries between the free word calculus, arbitrary
named equations, binary syntax and geometric paths.
