# Material imported definitions

Selected: `HewittSavage.category_zero_one`, `HewittSavage.polish_sequence_zero_one`.

- `TopologicalSpace`: The supplied topology on X and the actual product topology on all J-indexed tuples. Product opens have finite-coordinate basic neighborhoods.
- `IsOpen`: The open-set predicate of the supplied topology; used for the BP approximations and finite cylinders.
- `Dense`: Every point belongs to the closure; residual sets are dense in the explicitly Baire ambient space.
- `closure`: Intersection of all closed supersets, used in nowhere-density and density.
- `residual`: The filter generated by dense open sets with countable intersections; its members are comeagre sets. It need not be proper without a Baire/nonempty hypothesis.
- `IsMeagre`: The complement belongs to the residual filter. Equivalently the set is covered by countably many nowhere-dense sets; the alternatives concern A and its actual complement.
- `IsNowhereDense`: The interior of the closure is empty.
- `BaireMeasurableSet`: The set has the property of Baire: it differs from an open set by a meagre symmetric difference. Mathlib defines it via completion of the Borel sigma-algebra by the residual filter; the open-set characterization is proved, not definitional.
- `MeasurableSet`: Membership in the supplied sigma-algebra, instantiated with the Borel/residual completion in BaireMeasurableSet.
- `MeasurableSpace.generateFrom`: The sigma-algebra generated by the indicated sets; used to define Borel sets.
- `borel`: The sigma-algebra generated by the actual open sets.
- `eventuallyMeasurableSpace`: The sigma-algebra of sets agreeing modulo the specified filter with a measurable set.
- `EventuallyMeasurableSet`: Agreement modulo the filter with some measurable set.
- `Filter.EventuallyEq`: The equality set belongs to the filter; specialized here to category residual equality.
- `Filter.EventuallyEqSet`: Set membership agrees on a member of the filter.
- `CountableInterFilter`: The filter is closed under countable intersections.
- `Filter.countableGenerate`: The filter generated by the indicated base allowing countable intersections.
- `Countable`: A type injects into the natural numbers; countability only governs residual intersections, not the arbitrary infinite product index J.
- `Set.Countable`: The corresponding subtype is countable.
- `IsClosed`: The complement is open, used in closure and nowhere-density.
- `Continuous`: Open sets pull back to open sets; coordinate reindexing is continuous in both directions.
- `Homeomorph`: A bijection continuous in both directions; the actual reindexing map x maps to x composed with the coordinate permutation.
- `TopologicalSpace.induced`: The topology whose opens are generated by preimages through the indicated map; used in the product topology.
- `Filter`: An upward-closed family of sets containing the universe and closed under finite intersections; bottom is permitted until properness is proved.
- `Equiv`: Forward and inverse maps with both inverse laws. Equiv.Perm J is exactly J equiv J; the coordinate map is a genuine bijection.
- `PolishSpace`: The supplied topology is second countable and admits a compatible complete metric; used only in the Polish-sequence corollary.
- `SecondCountableTopology`: A countable family generates the supplied topology; the main arbitrary-index theorem does not impose this class.
- `TopologicalSpace.IsCompletelyMetrizableSpace`: A complete metric induces exactly the supplied topology, used in the Polish corollary.
- `CompleteSpace`: Every Cauchy filter converges in the compatible complete metric space.
- `Cauchy`: A nonbottom filter whose product is finer than the uniformity.
- `interior`: The largest open subset contained in the set; applied to closure in nowhere-density.
- `BaireSpace`: Every countable intersection of open dense sets is dense in the actual ambient space. The main theorem assumes this for X^J, not merely for each factor X.
- `Infinite`: The index type has no finite-type structure; a finite set of coordinates cannot exhaust it.
- `Set.Finite`: The corresponding subtype is finite, equivalently bijective with Fin n for some natural n. This is applied to all moved points of a permutation.

`HewittSavage.FiniteMoves σ` is fixed as `{j | σ j ≠ j}.Finite`. Finite is bijectivity with Fin n; Infinite excludes such finiteness. Perm J is J equiv J. The actual product topology is the infimum of induced coordinate topologies, with the retained finite-cylinder characterization. BaireMeasurableSet is connected to an open set modulo a meagre symmetric difference by a proved equivalence. The main Baire-product premise is explicit; the Polish-sequence instance is compiled. No probability measure law or stronger arbitrary-space original corollary is claimed.

theorem mem_countableGenerate_iff {s : Set α} :
    s ∈ countableGenerate g ↔ ∃ S : Set (Set α), S ⊆ g ∧ S.Countable ∧ ⋂₀ S ⊆ s := by
  constructor <;> intro h
  · induction h with
    | @basic s hs => exact ⟨{s}, by simp [hs]⟩
    | univ => exact ⟨∅, by simp⟩
    | superset _ _ ih => refine Exists.imp (fun S => ?_) ih; tauto
    | @sInter S Sct _ ih =>
      choose T Tg Tct hT using ih
      refine ⟨⋃ (s) (H : s ∈ S), T s H, by simpa, Sct.biUnion Tct, ?_⟩
      apply subset_sInter
      intro s H
      exact subset_trans (sInter_subset_sInter (subset_iUnion₂ s H)) (hT s H)
  rcases h with ⟨S, Sg, Sct, hS⟩
  refine mem_of_superset ((countable_sInter_mem Sct).mpr ?_) hS
  intro s H
  exact CountableGenerateSets.basic (Sg H)
