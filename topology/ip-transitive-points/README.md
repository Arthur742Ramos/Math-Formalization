# Generic IP-transitive points in weakly mixing systems

This is a development draft. For a continuous self-map `f` of a second-countable Baire Hausdorff space, if its coordinatewise square is open-set transitive, `IPTransitive.residual_ip_transitive` asserts that a residual set of points has IP entering times for every nonempty open set. The theorem permits time zero in the open-set transitivity hypothesis. Each IP witness is a sequence of strictly positive natural numbers; every sum over a nonempty finite set of distinct indices must be an entering time. The witness may depend on the point and the open set. For a nonempty space, `exists_dense_Gdelta_ip_transitive` supplies an actual nonempty dense G-delta family. Singleton spaces are handled explicitly. No converse or uniform sequence across open sets is asserted.

The source is Jian Li, *Transitive points via Furstenberg family*, Topology and its Applications 158 (2011), Theorem 3.2 (1)⇒(2), https://arxiv.org/abs/1103.3412v2. Li states the compact metric theorem and uses infinitely many hitting times in the transitivity convention. This development proves the forward conclusion under the more general assumptions above, with the repository's time-zero-permitting open-set transitivity. It separately proves square hitting times are infinite; the main proof derives positive simultaneous returns before constructing IP sums. The source's intermediate orbit-closure assertion is not used as a standalone unrestricted hypothesis: time-zero closure alone does not ensure a positive return.

Li uses IP point transitivity to study dynamical classification and disjointness from minimal distal systems (Corollary 5.3), providing a concrete audience in topological dynamics. This package does not formalize that disjointness application or claim a new mathematical theorem.

The proof adapts the generic dense-orbit, Kuratowski–Ulam section, and pair-iteration fragments with immutable commit/path/blob attribution in the source header. It then proves positive-return and finite-prefix extension lemmas, recursively constructs a positive generator sequence, and connects it to generic product-transitive pairs. The Challenge contains a standalone copy; the Solution imports the separate source module.
