# Material imported definitions

Selected declaration: `KnasterReichbach.exists_homeomorph_extension`.

- `TopologicalSpace`: The supplied open-set topology; all homeomorphism conclusions use this same topology.
- `IsOpen`: The open-set predicate of the supplied topology.
- `IsClosed`: A set whose complement is open; used for closure and Gδ facts.
- `closure`: Intersection of all closed supersets; equivalently every neighborhood intersects the original set.
- `Continuous`: Preimages of open sets are open; both directions are required by a homeomorphism.
- `Homeomorph`: An equivalence with continuous forward and inverse maps. It gives a bijection of the actual subspaces.
- `TopologicalSpace.induced`: Preimages of ambient opens define the topology; the subtype instance uses the inclusion.
- `Filter`: An upward-closed collection of sets containing univ and closed under finite intersections; bottom is allowed until NeBot is supplied.
- `Equiv`: Forward and inverse maps with left and right inverse laws; Homeomorph adds continuity.
- `IsNowhereDense`: The interior of the ambient closure is empty; for closed A this means A has empty interior.
- `IsClopen`: Both closed and open in the ambient topology, used for finite partition cells.
- `interior`: Union of the open sets contained in the set.
- `IsCompact`: Every nonbottom filter on the set admits a cluster point in it; used to obtain nonempty nested fiber intersections.
- `CompactSpace`: The whole ambient space is compact. Cantor space uses the standard compact product topology.

CantorSpace is the project abbreviation for Nat -> Bool, using the existing Pi topology, not a chosen finer topology. Subsets use the induced topology. Homeomorph supplies a bijection and continuity in both directions; exact agreement is equality of ambient values. No nonemptiness or extension-existence premise is added. Imported compactness and clopen separation supply infrastructure; the matched refinements and full extension are project proofs. Retained provenance alone does not establish inventory completeness; independent review is required.

Filter: https://github.com/leanprover-community/mathlib4/blob/065356127b1dc0016f66b7283ce0ce2c4055aa55/Mathlib/Order/Filter/Defs.lean#L71-L83

```lean
/-- A filter `F` on a type `α` is a collection of sets of `α` which contains the whole `α`,
is upwards-closed, and is stable under intersection. We do not forbid this collection to be
all sets of `α`. -/
@[to_dual_dont_translate]
structure Filter (α : Type*) where
  /-- The set of sets that belong to the filter. -/
  sets : Set (Set α)
  /-- The set `Set.univ` belongs to any filter. -/
  univ_sets : Set.univ ∈ sets
  /-- If a set belongs to a filter, then its superset belongs to the filter as well. -/
  sets_of_superset {x y} : x ∈ sets → x ⊆ y → y ∈ sets
  /-- If two sets belong to a filter, then their intersection belongs to the filter as well. -/
  inter_sets {x y} : x ∈ sets → y ∈ sets → x ∩ y ∈ sets
```
