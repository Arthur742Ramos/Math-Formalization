# Material imported definitions

Selected: EZero.finite_flip_mixing, EZero.zero_one, EZero.generically_constant, EZero.no_baire_reduction, EZero.no_borel_reduction.

- `TopologicalSpace`: The actual supplied source and target topologies.
- `IsOpen`: Open in the supplied source/target topology, or the actual induced subtype topology; relative opens are restrictions of ambient opens.
- `Dense`: Closure equals the whole actual Cantor space; residual sets are dense by its Baire-space instance, supporting the nonempty intersection argument.
- `closure`: Intersection of all closed supersets, used in nowhere-density and density.
- `residual`: The filter generated by dense open sets with countable intersections; its members are comeagre sets. It need not be proper without a Baire/nonempty hypothesis.
- `IsMeagre`: Complement membership in the residual filter. The zero_one conclusion states that A is meagre or its complement is meagre; this yields the residual membership choices used for generic constancy.
- `IsNowhereDense`: The interior of the closure is empty.
- `BaireMeasurableSet`: The set has the property of Baire: it differs from an open set by a meagre symmetric difference. Mathlib defines it via completion of the Borel sigma-algebra by the residual filter; the open-set characterization is proved, not definitional.
- `MeasurableSet`: Membership in the supplied sigma-algebra, instantiated with the Borel/residual completion in BaireMeasurableSet.
- `MeasurableSpace.generateFrom`: The sigma-algebra generated by the indicated sets; used to define Borel sets.
- `borel`: The sigma-algebra generated by the actual open sets.
- `eventuallyMeasurableSpace`: The sigma-algebra of sets agreeing modulo the specified filter with a measurable set.
- `EventuallyMeasurableSet`: Agreement modulo the filter with some measurable set.
- `Filter.EventuallyEq`: The equality set belongs to the filter; specialized here to category residual equality.
- `Filter.EventuallyEqSet`: Set membership agrees on a member of the filter.
- `CountableInterFilter`: The filter is closed under countable intersections.
- `Filter.countableGenerate`: The filter generated by the indicated base allowing countable intersections.
- `Countable`: A type injects into the natural numbers, governing dense-set covers and residual intersections.
- `Set.Countable`: The corresponding subtype is countable.
- `IsClosed`: The complement is open, used in closure and nowhere-density.
- `Continuous`: Actual continuity of the Boolean xor homeomorphisms; invariant maps need only BP preimages, not continuity.
- `Filter`: An upward-closed family of sets containing the universe and closed under finite intersections; bottom is permitted until properness is proved.
- `interior`: The largest open subset contained in the set; applied to closure in nowhere-density.
- `BaireSpace`: Countable intersections of open dense subsets are dense. Inferred for the actual nonempty Cantor product in the category arguments, not added as a selected premise; finite_flip_mixing itself needs no Baire assumption.
- `SecondCountableTopology`: A countable family generates the actual target topology; a countable open basis separates values together with T0.
- `IsTopologicalBasis`: A covering family directed downwards around points generates the actual topology; synchronized membership in its countable sets implies equality by T0. No continuity of the invariant map is asserted.
- `TopologicalSpace.generateFrom`: The topology whose opens are GenerateOpen of the family: it contains the generators and universe and closes under binary intersections and arbitrary unions. Distinct from MeasurableSpace.generateFrom, which generates a sigma-algebra.
- `Homeomorph`: A bijective continuous map with continuous inverse on the actual Cantor product; here the xor-mask map is its own inverse and a finite flip or full complement is a special mask.
- `Equiv`: A function and inverse with both inverse laws, used in actual coordinate-value xor-mask homeomorphisms, not coordinate reindexing.
- `T0Space`: Distinct target points are not inseparable; equivalent to an open set containing exactly one of them. Together with a basis this turns common open-membership into equality.
- `Measurable`: Every measurable target set has measurable inverse image; the selected Borel result explicitly supplies the Borel sigma-algebras on both spaces.
- `BorelSpace`: The supplied measurable structure equals the Borel sigma-algebra. In the Borel bridge both measurable structures are literally chosen to be borel.
- `Finset`: A duplicate-free multiset of coordinate indices, hence a finite set; flipping exactly these Boolean values defines the selected genuine finite-change homeomorphism.

BP/open-modulo-meagre, T0 open separation and residual characterizations are proved equivalences, not definitional equality claims. The product topology, Boolean discreteness, tail relation, xor actions and explicit Borel structures have literal/compiled bridges. No target Polish hypothesis or E0 class-size theorem is asserted.

theorem mem_countableGenerate_iff {s : Set α} :
    s ∈ countableGenerate g ↔ ∃ S : Set (Set α), S ⊆ g ∧ S.Countable ∧ ⋂₀ S ⊆ s := by
  constructor <;> intro h
  · induction h with
    | @basic s hs => exact ⟨{s}, by simp [hs]⟩
    | univ => exact ⟨∅, by simp⟩
    | superset _ _ ih => refine Exists.imp (fun S => ?_) ih; tauto
    | @sInter S Sct _ ih =>
      choose T Tg Tct hT using ih
      refine ⟨⋃ (s) (H : s ∈ S), T s H, by simpa, Sct.biUnion Tct, ?_⟩
      apply subset_sInter
      intro s H
      exact subset_trans (sInter_subset_sInter (subset_iUnion₂ s H)) (hT s H)
  rcases h with ⟨S, Sg, Sct, hS⟩
  refine mem_of_superset ((countable_sInter_mem Sct).mpr ?_) hS
  intro s H
  exact CountableGenerateSets.basic (Sg H)

/-- A filter `F` on a type `α` is a collection of sets of `α` which contains the whole `α`,
is upwards-closed, and is stable under intersection. We do not forbid this collection to be
all sets of `α`. -/
@[to_dual_dont_translate]
structure Filter (α : Type*) where
  /-- The set of sets that belong to the filter. -/
  sets : Set (Set α)
  /-- The set `Set.univ` belongs to any filter. -/
  univ_sets : Set.univ ∈ sets
  /-- If a set belongs to a filter, then its superset belongs to the filter as well. -/
  sets_of_superset {x y} : x ∈ sets → x ⊆ y → y ∈ sets
  /-- If two sets belong to a filter, then their intersection belongs to the filter as well. -/
  inter_sets {x y} : x ∈ sets → y ∈ sets → x ∩ y ∈ sets
