# Mathematical and source provenance

The selected results are E. Abo-Zeid, [*Some properties of Whitney continua*, Topology Proceedings 3 (1978), 301-312, Theorems 2.1 and 2.2, pp. 303-304](https://topology.nipissingu.ca/tp/reprints/v03/tp03201.pdf). The paper defines Whitney maps on C(X), states that Whitney levels are continua, and uses Brouwer reduction to obtain an irreducible covering family. This proof establishes level connectedness directly and obtains the minimal covering family by minimizing a continuous strictly increasing height function on the compact set of covering continua. The relative form of Theorem 2.1 supplies Theorem 2.2 without a separate C(Y) homeomorphism.

Alejandro Illanes, [*Size levels of hyperspaces*, Topology Proceedings 26 (2001-2002), 213-233, p. 214](https://topology.nipissingu.ca/tp/reprints/v26/tp26115.pdf), documents the more general classical size-level continuum fact. This package proves that supporting fact for relative levels, then applies it to genuine Whitney maps. The source authors have not been contacted.

Seven support modules are retained from Arthur742Ramos/Math-Formalization, [commit eb3bac386e34b97d443cfcf0bd603e34ccdac6d0](https://github.com/Arthur742Ramos/Math-Formalization/tree/eb3bac386e34b97d443cfcf0bd603e34ccdac6d0/topology/hyperspace-components). `Boundary`, `Checkpoint`, `Scalar`, `Hyperspace`, `Chain`, `Parameter`, and `OrderArc` supply the existing order-arc construction. The common Boundary source is stored once. Where Windows checkout changed LF to CRLF, `reuse.json` records original and retained byte identities and that exact newline transformation. Source headers and licensing are preserved.

The boundary-bumping lineage originates in [boundary-bumping-lean, commit 58831416a12f73312ac01cdaec19c060a6d4b142](https://github.com/Arthur742Ramos/boundary-bumping-lean/tree/58831416a12f73312ac01cdaec19c060a6d4b142). The retained order-arcs folder documents the earlier source ancestry. `Levels.lean`, `Reduction.lean`, `Solution.lean` and the independent Challenge are new for this target.

Verification infrastructure adapts the existing owned hyperspace-components scripts. The definition dossier retains complete Mathlib and Lean source files with original headers, Apache-2.0 license snapshots, commit and Git blob identities, hashes, and complete indexed declaration ranges. All mathematical code uses Apache-2.0. The local cache was read through ordinary files, copied into this owned workspace, and compared byte for byte against the qualified exact-pin inventory. No shared cache was modified.
