# Literal topology definitions

This package imports Mathlib's actual lower-limit real line, with topology
generated by half-open intervals `Ico a b`. Arbitrary subspaces carry its induced
subtype topology. The ordinary real topology is used only in the countable-cover
argument and does not replace the Sorgenfrey topology.

The statements use standard `IsLindelof`, `LindelofSpace`,
`HereditarilyLindelofSpace`, `ParacompactSpace`, `IsClopen`, `LocallyFinite`,
`Set.Countable`, `Pairwise`, and `Disjoint`. Covering and subordination are literal
unions, equality to `Set.univ`, and set containment. No replacement predicate
assumes the theorem conclusion.

`definition-evidence/manifest.json` indexes complete attributed files from the
pinned Mathlib commit, with Git blob, SHA-256, byte length, source URL and relevant
declarations. The checker compares them directly with installed pinned Git
sources and rejects corrupted bytes.

`Challenge.lean` independently spells out seven target propositions using only
upstream definitions. `scripts/CompareTypes.lean` assigns the corresponding
proofs to them through ordinary Lean type checking. This local contract format
has no theorem holes and makes no external registry comparator claim.
