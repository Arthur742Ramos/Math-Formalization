# Material imported definition: property of Baire

Both `KuratowskiUlam.isMeagre_iff_eventually_sections` and
`KuratowskiUlam.residual_iff_eventually_sections` assume
`hA : BaireMeasurableSet A` for `A : Set (X × Y)`.
This document retains the exact material definition and its semantic dependency
chain, so the hypothesis can be audited without retrieving a moving web page.

## Meaning and both converse proofs

The literal definition uses the sigma-algebra of Borel sets modulo equality on
a residual set. The earlier explicit parameter `m : MeasurableSpace α` in
EventuallyMeasurable.lean is part of `eventuallyMeasurableSpace`'s signature:
its two arguments here are `(borel Z)` and `(residual Z)`. The retained
parameter-context excerpt makes that elaboration explicit. Unfolding gives a Borel set B with
`∀ᶠ z in residual Z, z ∈ A ↔ z ∈ B`. Here the Borel sigma-algebra is generated
by all open sets of the given topology. The residual filter consists of sets
containing a countable intersection of dense open sets. A meagre set is one whose
complement is residual; equivalently it is contained in a countable union of
sets whose closures have empty interior. Residual need not imply dense in an
arbitrary space.

The open-set formulation is a **proved equivalence**, not the literal definition:
`BaireMeasurableSet A ↔ ∃ O, IsOpen O ∧ IsMeagre (A ∆ O)`.
The upstream theorem `BaireMeasurableSet.iff_residualEq_isOpen` supplies the open
representative; residual equality of sets means membership agrees residually,
which is exactly meagreness of their symmetric difference. This equivalence
needs only `TopologicalSpace Z`, with independent arbitrary universes and no
Baire, separation, countability or nonemptiness assumption. It describes the
property of Baire; no sigma-algebra generated by continuous real-valued
functions is substituted.

In `isMeagre_iff_eventually_sections`, the existing proof takes this open
representative O using `hA.residualEq_isOpen`. The disagreement set is meagre.
The forward section result carries that disagreement to generically meagre
sections. Together with the assumed generic meagreness of A's sections, it
makes O's sections generically meagre. If O were nonempty it would contain a
nonempty open rectangle. Baireness of X finds a good parameter in its first
coordinate, and baireness of Y rules out a nonempty open meagre fiber. Thus O
is empty and A is meagre. Both Baire hypotheses are retained, as is the
countable pi-base hypothesis on Y. No category pullback along a fixed section
is assumed to preserve Baire measurability.

In `residual_iff_eventually_sections`, `hA.compl` supplies precisely the same
property for the complement. Applying the meagre equivalence to the complement
and unfolding `IsMeagre`, double complement and inverse-image complement yields
the residual equivalence. This introduces no new assumptions.

`ChallengeTests.lean` and `SemanticTests.lean` each check the literal definition,
its Borel-modulo-residual unfolding, the open/symmetric-difference equivalence
in both directions, complement stability and both original converse contracts
under that explicit classical hypothesis. They compile independently through
Challenge and Solution. The selected seven theorems, two local definitions,
proof files and Comparator configuration are unchanged by this audit evidence.
Passing a local build does not certify a corrected commit's canonical kernels,
rendering, editorial decision or registration; those require separate receipts.

theorem MeasurableSet.residualEq_isOpen [MeasurableSpace α] [BorelSpace α] (h : MeasurableSet s) :
    ∃ u : Set α, IsOpen u ∧ s =ᵇ u := by
  induction s, h using MeasurableSet.induction_on_open with
  | isOpen U hU => exact ⟨U, hU, .rfl⟩
  | compl s _ ihs =>
    obtain ⟨U, Uo, hsU⟩ := ihs
    use (closure U)ᶜ, isClosed_closure.isOpen_compl
    exact .compl <| hsU.trans <| .symm <| closure_residualEq Uo.isLocallyClosed
  | iUnion f _ _ ihf =>
    choose u uo su using ihf
    exact ⟨⋃ i, u i, isOpen_iUnion uo, .countable_iUnion su⟩

def eventuallyMeasurableSpace (l : Filter α) [CountableInterFilter l] : MeasurableSpace α where

lemma isMeagre_iff_countable_union_isNowhereDense {s : Set X} :
